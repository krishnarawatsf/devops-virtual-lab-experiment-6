Interactive Q&A
Basic
What is Continuous Integration (CI)?
Click to hide answer
CI is the software practice where developers integrate code into a shared repository multiple times daily, automatically validated by builds and automated tests to detect bugs early.
Basic
What is Apache Maven & pom.xml?
Click to hide answer
Maven is a build automation and dependency manager. The pom.xml (Project Object Model) defines build configs, plugins, source directories, and dependency coordinates.
Intermediate
Smoke Testing vs Regression Testing?
Click to hide answer
Smoke Testing: Wide & shallow sanity check verifying critical runtime/memory stability (<50ms).
Regression Testing: Comprehensive parameterized tests verifying new code didn't break existing features.
Intermediate
Freestyle Project vs Pipeline as Code?
Click to hide answer
Freestyle jobs are configured manually via the web UI. Pipelines are codified in version-controlled Jenkinsfile scripts, supporting stages, error handling, and multi-branch automation.
Advanced
How do Webhooks trigger Jenkins builds?
Click to hide answer
GitHub sends an HTTP POST payload to /github-webhook/ instantly when commits are pushed. Jenkins intercepts this payload and triggers the corresponding pipeline with zero delay.
Advanced
How does Maven resolve Transitive Dependencies?
Click to hide answer
Maven uses dependency mediation ("nearest-definition" in POM hierarchy) and caches libraries in ~/.m2/repository to eliminate redundant network downloads.
